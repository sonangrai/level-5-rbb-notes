The sidebar search is reachable from anywhere, and every interactive element in
the shell is a real button or link — nothing here needs a pointer.

## Shortcuts

| Key | What it does |
| --- | --- |
| `/` | Focus the sidebar search |
| `Escape` | Clear the search, or close the sidebar on mobile |
| `Tab` | Move through the document list in reading order |

## Skip link

The first `Tab` from a fresh page focuses a skip link that jumps past the
header and sidebar, straight to the document.

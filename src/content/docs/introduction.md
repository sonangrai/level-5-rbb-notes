RBB Notes is a living reference. Each entry in the sidebar is one Markdown file,
and the file you pick is rendered here in the main column.

## How it is organised

Documents are grouped into sections. A section is a theme, not a hierarchy —
nothing nests deeper than one level, which keeps the sidebar readable at a
glance.

- **Getting started** — orientation, conventions, setup.
- **Guides** — task-shaped walkthroughs you follow end to end.
- **Reference** — facts you look up and leave.

## Where the content lives

Everything on this page comes from `src/content/docs/introduction.md`. Drop a new
`.md` file in that folder and it appears in the sidebar and gets its own URL.

> [!NOTE]
> The frontmatter block at the top of each file supplies the title, summary,
> section and tags. Nothing else has to be registered anywhere.
